# T3 — OutputReview shows artifact (B2/B4)

## Goal
Spec §6.3 + §8.5: Output Review is a single panel that renders Markdown, code
diff, HTML preview, and image preview — no separate Artifact tab. Backend
already emits `payload.summary` (B2: wrong key) and the task's own artifacts
(B4: wrong "latest completed phase" lookup).

## Approach
Per user instruction: "merge ArtifactTab into OutputReviewTab", fix the key,
match artifact to the current gate's taskId.

## Files changed
- `frontend/src/store/useUiStore.ts`: removed `'artifact'` from `InspectorTab`
  union (no longer a valid tab).
- `frontend/src/services/api/sdlcApi.ts`:
  - `GateItem.payload.summary` replaces stale `outputSummary` (kept nothing —
    the wrong key was unused outside this one component, so removal is safe).
- `frontend/src/pages/SdlcDashboard/components/InspectorPanel.tsx`:
  - TABS list no longer includes the artifact entry.
  - `tab === 'artifact'` render removed.
  - `OutputReviewInline` now:
    - reads `payload.summary` (correct backend key) instead of `outputSummary`.
    - fetches artifacts via `getSdlcTaskStatus(gate.taskId)` keyed to the
      CURRENT gate (no stale-phase mismatch).
    - renders the artifacts inline below the summary via the new
      `ArtifactSection` / `ArtifactBlock` components.
  - `ArtifactTab` component deleted (was the source of the duplicate tab).
  - New `ArtifactBlock` renders:
    - HTML mockup → sandboxed iframe (`srcDoc`, `sandbox=""`).
    - Code diff → monospace `<pre>`.
    - Image (data URL in any JSON field) → `<img>`.
    - Default text → `react-markdown` rendering.
    - Default JSON → collapsible `<details>` with pretty-print.
- `frontend/src/pages/SdlcDashboard/components/AgentOutputPanel.tsx`:
  - `gate?.payload.outputSummary` → `gate?.payload.summary` (two sites). Same
    backend key fix in the legacy modal.
- `frontend/src/pages/SdlcDashboard/index.tsx`:
  - When a "drill into phase" click finds no pending review gate, route to
    `'runtime'` instead of the (now-removed) `'artifact'` tab.

## Decisions captured
- HTML preview uses `<iframe sandbox="">` so the UX agent's full HTML doc
  cannot escape into the host page (defense against prompt-injected
  `<script>`).
- Image detection scans JSON fields `image_data | image | dataUrl | screenshot`
  for `data:image/...` data URLs — pragmatic, matches what ARCH/UX/QA
  agents currently emit.
- Artifact ordering: priority list `prd → ux_spec → html_mockup → patch_diff
  → mock_code_diff → qa_report → architecture_brief` so the headline content
  appears first when multiple artifacts share a task.
